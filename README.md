# Cairn — Intentional Viewing

Cairn is a Chrome extension that helps people use desktop YouTube with a plan.
It quiets distracting surfaces, asks for a viewing intention, and adds a pause
before changing Focus Mode.

This public repository hosts Cairn's [privacy policy](PRIVACY.md),
[support information](SUPPORT.md), and approved Chrome Web Store images in
[`assets/`](assets/). It does not contain the extension source or release ZIP.

Cairn is independent and is not affiliated with or endorsed by Google or
YouTube.
