# Cairn — Intentional Viewing

Cairn is a Chrome extension that helps people use desktop YouTube with a plan.
It quiets distracting surfaces, asks for a viewing intention, and adds a pause
before changing Focus Mode.

This public repository powers Cairn's [landing site](https://mohdashraf010897.github.io/cairn-public/),
[privacy policy](PRIVACY.md) ([web view](https://mohdashraf010897.github.io/cairn-public/privacy/)),
[support hub](SUPPORT.md) ([web view](https://mohdashraf010897.github.io/cairn-public/support/)),
and Chrome Web Store assets in [`assets/`](assets/). It does not contain the extension source or release ZIP.

Cairn is independent and is not affiliated with or endorsed by Google or
YouTube.
