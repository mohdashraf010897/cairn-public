Cairn Support

For help with Cairn, visit the Chrome Web Store Support hub or open an issue in the public Cairn repository. Need to reinstall Cairn on desktop Chrome? Open the official Chrome Web Store listing.

What to include in a bug report

  • Your browser and version (for example, Chrome 134 on macOS)
  • Cairn version (shown in Cairn Settings or chrome://extensions)
  • Which YouTube surface was affected (Home, Search results, Watch page, or Shorts URL)
  • What you expected and what happened instead

Privacy reminder: Do not post Lock PINs, browsing history, private viewing intentions, or personal data in a public issue.

Quick troubleshooting

  • YouTube tab opened before installing Cairn? Refresh that open YouTube tab once so Chrome attaches the content script.
  • Want to reset all local data or export settings? Right-click the Cairn icon in your Chrome toolbar → Options → Data & Reset.
  • Curious what data lives where? Read the Privacy Policy.
